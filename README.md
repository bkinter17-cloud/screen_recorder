# Screen Recorder

برنامج Desktop احترافي لتسجيل شاشة Windows، مبني بـ Python 3.12+ وPySide6 وFFmpeg.

## آخر التحديثات (بناءً على اختبار حقيقي على Windows)

بعد اختبارك الفعلي للنسخة السابقة على Windows، تم إصلاح/إضافة:

- **🐛 إصلاح حرج**: مصدر الصوت لم يكن موصولاً فعلياً بزر "بدء التسجيل" —
  الآن يوجد اختيار حقيقي (بدون صوت / ميكروفون فقط / صوت النظام فقط /
  كلاهما) في صفحة الرئيسية، مع قوائم أجهزة حقيقية وزر تحديث.
- **🪟 إخفاء النافذة + لوحة تحكم عائمة**: عند بدء التسجيل، تختفي النافذة
  الرئيسية تلقائياً وتظهر لوحة صغيرة عائمة (بلا إطار، فوق كل النوافذ،
  قابلة للسحب) فيها المؤقت الحي وأزرار إيقاف مؤقت/إنهاء/إظهار النافذة.
- **🎬 صفحة التسجيلات مكتملة**: عرض كل التسجيلات مرتبة بالتاريخ (الاسم،
  المدة الحقيقية عبر ffprobe، الحجم)، مع فتح المجلد، تشغيل، إعادة تسمية،
  وحذف (بتأكيد).
- **🎨 تصميم مُعاد بالكامل**: نظام ألوان مقصود (رمادي غرافيتي + كهرماني
  للتحديد + أخضر/أحمر دلالي لأزرار البدء/الإيقاف)، تدرج طباعي أوضح،
  مسافات أوسع، بدل الألوان الافتراضية العامة السابقة.
- **↔️ دعم RTL فعلي على مستوى التطبيق**: كانت الواجهة تُعرض LTR رغم أن كل
  المحتوى عربي. الآن `app.setLayoutDirection(Qt.RightToLeft)` يُطبَّق من
  `main.py` تلقائياً (الشريط الجانبي على اليمين، محاذاة صحيحة للنصوص
  والنماذج بالكامل).

## نظرة عامة على المشروع

تطبيق سطح مكتب لتسجيل الشاشة قريب من OBS/ShareX في الوظائف الأساسية بواجهة
أبسط: تسجيل الشاشة/نافذة/منطقة مخصصة، صوت (ميكروفون + صوت النظام)، لقطات
شاشة، اختصارات عامة، اكتشاف مُرمِّزات العتاد تلقائياً، وتشخيص كامل للجهاز.

FFmpeg هو المكوّن الخارجي المسؤول عن كل التقاط وترميز الفيديو فعلياً —
بايثون هنا طبقة تنسيق وواجهة فقط، دون إعادة اختراع أي محرك ترميز.

## ⚠️ ملاحظة صادقة حول بيئة التطوير/الاختبار

كل الأكواد في هذا المشروع **اختُبرت بتشغيل فعلي حقيقي** (تسجيل فيديو حقيقي،
التقاط صوت حقيقي بتحليل FFT، بناء EXE فعلي وتشغيله...) لكن ضمن بيئة تطوير
Linux (Xvfb لشاشة وهمية، PulseAudio للصوت). هذا يعني:

- **يعمل ويُختبر بالكامل هنا**: FFmpeg، الإعدادات، الـ Logging، منطق
  Pause/Resume، مزج الصوت، اكتشاف المُرمِّزات مع Fallback، لقطة الشاشة،
  الواجهة الكاملة، نافذة الإعدادات، Diagnostics، وآلية البناء (build.py).
- **مصمَّم بشكل صحيح لكن غير قابل للاختبار الكامل هنا لأنه خاص بـ Windows
  فعلياً**: التقاط الشاشة عبر `gdigrab` (نستخدم `x11grab` كبديل مكافئ فقط
  للاختبار على Linux)، اكتشاف النوافذ عبر `pywin32`، الاختصارات العامة
  الفعلية (تحتاج جهاز إدخال حقيقي غير متوفر في حاوية Linux)، WASAPI
  loopback الحقيقي (نستخدم PulseAudio monitor كمكافئ للاختبار)،
  والتشغيل مع بدء Windows (يحتاج تسجيل في الـ Registry).
- **يتطلب اختباراً يدوياً إضافياً على جهاز Windows حقيقي قبل الاعتماد
  الكامل عليه في الإنتاج**: خصوصاً مُرمِّزات NVENC/QuickSync/AMF الفعلية
  (لم تُختبر هنا لعدم توفر عتاد مطابق)، وبناء EXE فعلي عبر `build.py`
  (اختُبر هنا بإنتاج ثنائي Linux فقط، لإثبات صحة آلية السكربت).

## المتطلبات

- Windows 10/11 (بيئة الإنتاج المستهدفة)
- Python 3.12+
- FFmpeg مثبَّت ومتاح في PATH، أو مساره محدَّد من Settings -> Advanced

## التثبيت

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### تثبيت FFmpeg على Windows

1. حمّل build جاهز من [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) أو
   [ffmpeg.org](https://ffmpeg.org/download.html).
2. فك الضغط وأضف مجلد `bin` إلى متغير النظام PATH، **أو**
3. اترك المسار في PATH فارغاً وحدّد `ffmpeg.exe` يدوياً من داخل التطبيق
   عبر Settings -> Advanced -> FFmpeg Path.

## الميزات الرئيسية

| الميزة | التفاصيل |
|---|---|
| التسجيل | شاشة كاملة/محددة، جودة (منخفضة→عالية جداً)، FPS قابل للاختيار |
| الصوت | ميكروفون + صوت النظام (WASAPI loopback)، مزج حي، VU meter، كتم |
| Pause/Resume | تعليق عملية FFmpeg فعلياً (صفر استهلاك CPU أثناء الإيقاف) |
| الحماية | تسجيل أولي إلى MKV مؤقت، تحويل آمن للصيغة النهائية بعد الإيقاف |
| Screenshot | شاشة كاملة/منطقة/شاشة محددة، PNG أو JPG، أسماء بلا تصادم |
| Hotkeys | عامة (تعمل حتى والنافذة غير نشطة)، قابلة للتخصيص، كشف تعارض |
| Hardware Encoding | فحص فعلي لكل مُرمِّز (وليس افتراضاً)، Auto/Software/NVIDIA/Intel/AMD |
| Diagnostics | معلومات جهاز حقيقية + زر نسخ، بدون أي اتصال بالإنترنت |
| Webcam | اختياري بالكامل، صفر تأثير على التسجيل عند التعطيل |

## الاختبارات

```bash
pytest tests/ -v
```

26 اختباراً تغطي: الإعدادات، بناء أوامر FFmpeg واكتشافه، اكتشاف المُرمِّزات
(فحص فعلي لـ libx264 والتحقق من fallback عند طلب مُرمِّز عتاد غير متوفر)،
الاختصارات العامة وكشف التعارض، تسمية لقطات الشاشة بدون تصادم، وحسابات
موضع الـ webcam overlay.

> ملاحظة: الاختبارات المذكورة أعلاه لا تحتاج شاشة أو صوت حقيقي لتعمل.
> الاختبارات التكاملية الأعمق (تسجيل فيديو+صوت حقيقي فعلي، تشغيل الواجهة
> بالكامل، بناء EXE) نُفّذت يدوياً أثناء التطوير عبر Xvfb/PulseAudio ولم
> تُدرَج في `pytest` التلقائي لأنها تتطلب تلك البيئة الافتراضية تحديداً.

## بناء EXE

```bash
python build.py
```

- على Windows: يُنتج `dist/ScreenRecorder/ScreenRecorder.exe` قابلاً للتشغيل مباشرة.
- على Linux/macOS: يُنتج ثنائياً لنفس النظام فقط (مفيد للتحقق من صحة
  آلية البناء نفسها، وليس للتوزيع على مستخدمي Windows).

FFmpeg **لا** يُضمَّن تلقائياً داخل الحزمة (لأسباب الترخيص وحجم الملف) —
يبحث التطبيق عنه في PATH، أو يمكن تحديد مساره يدوياً من Settings بعد
وضع `ffmpeg.exe` بجانب الملف التنفيذي.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| "لم يتم العثور على FFmpeg" عند بدء التطبيق | ثبّت FFmpeg وأضفه لـ PATH، أو حدّد مساره من Settings -> Advanced |
| لا تظهر أي شاشة في القائمة | تحقق من Diagnostics — قد تحتاج صلاحيات إضافية على بعض إعدادات Windows |
| الاختصارات العامة لا تعمل | بعض برامج مكافحة الفيروسات تحجب global hooks — أضف استثناءً للتطبيق |
| صوت النظام لا يُسجَّل | تحقق من Diagnostics أن جهاز Loopback مكتشف؛ جرّب إعادة تشغيل التطبيق بعد توصيل سماعات جديدة |
| فشل بناء EXE | تأكد من `pip install pyinstaller` وأنك تُشغّل `build.py` من جذر المشروع |

راجع `logs/app.log` دائماً لتفاصيل أي خطأ (يحتفظ بآخر 5 ملفات بحد 5MB لكل واحد).
